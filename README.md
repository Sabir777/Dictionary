# Dictionary (Словарь: ru-en)

Данное приложение будет являться моим помощником в изучении английского языка. Так я буду накапливать слова и их значения и в конечном итоге запоминать их. Конечная цель - научиться читать документацию на английском языке

***

### Бэкап и восстановление базы данных

Файл с базой данных я в git не сохраняю
В репозитории будет храниться только бэкап базы данных

Бэкап базы данных в файл SQL можно сделать с помощью команды:
```shell
sqlite3 app/db/dictionary.db .dump > app/db/dictionary.sql
```
> Нахожусь в корне проекта

Восстановление базы данных можно сделать с помощью команды:
```shell
sqlite3 app/db/dictionary.db < app/db/dictionary.sql
```
> Нахожусь в корне проекта

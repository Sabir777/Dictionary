# Dictionary (Словарь: ru-en)

Данное приложение будет являться моим помощником в изучении английского языка. Так я буду накапливать слова и их значения и в итоге запоминать их. Конечная цель - научиться читать документацию на английском языке

***

### Бэкап и восстановление базы данных

Файл с базой данных я в git не сохраняю.
В репозитории будет храниться только бэкап базы данных
***
##### Запуск основного приложения выполняется командой
```
./run.sh
```
> Запускать в корне проекта

***
##### Бывает полезным восстановление БД: если происходили изменения то при выполнении git pull будет скачен бэкап обновленной БД.
- При запуске основного приложения командой `./run.sh` бэкап будет затерт старой версией БД
- Поэтому вначале нужно ВОССТАНОВИТЬ БД из бэкапа
- Восстановление базы данных можно сделать с помощью команды:
```shell
./recovery_db.sh
```
> Нахожусь в корне проекта

***
Бэкап базы данных в файл SQL можно сделать с помощью команды:
```shell
./backup_db.sh
```
> Нахожусь в корне проекта

***
### Пакетная вставка переводов
Алгоритм:
1) Перевожу предложение - получаю английский и русский контекст
2) Добавляю контекст
3) Отправляю на обработку AI оба контекста и даю задания сопоставить пары слов (переводы) и оформить их в кортежи
4) Добавляю сопоставления в app/insert.py и указываю ID контекста
5) Запускаю в корне проекта скрипт
```
./insert.sh
```

##### Итог: выполняется пакетное добавление переводов в мой словарь

> После клонирования (pull`а) на другом устройстве выполнить вначале `./recovery_db.sh`
